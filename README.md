# Tilbakemeldinger om Svøm!

Brukere av svømmeappen Svøm! kan legge igjen tilbakemeldinger, feilmeldinger og ønsker ved å opprette en "issue" på denne siden. 

En slik issue kan brukes til å beskrive hva som ikke fungerer, forslag til forbedringer eller andre kommentarer som kan hjelpe oss med å forbedre appen. Det er nyttig å inkludere så mye informasjon som mulig, for eksempel hva du gjorde, hvilke symptomer du så, og hvilke forventninger du hadde, slik at problemet lettere kan forstås og løses.
